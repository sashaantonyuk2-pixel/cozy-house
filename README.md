# CozyHouseVibe

Online store for cozy home goods: ceramics, textiles, lighting and décor.

- `index.html` — the live storefront (English). Served by GitHub Pages.

The admin panel is kept separately and is not part of this repository.

## Як оновлювати сайт

1. Відкрийте робочий файл `CozyHouseVibe_Store.html` у себе на комп'ютері й перейдіть в адмін-панель («⚙ Admin» унизу сторінки).
2. Змініть товари, ціни, фото чи тексти. Усе зберігається лише у вашому браузері, тому час від часу робіть резервну копію (.json).
3. Відкрийте «Публікація й копії» і натисніть «Завантажити сайт (index.html)».
4. Тут, на GitHub, замініть `index.html` новим файлом: **Add file → Upload files → Commit changes**. Сайт оновиться за 1–2 хвилини.

## Хостинг

Settings → Pages → Source: *Deploy from a branch*, Branch: `main`, folder `/ (root)`.
