# База даних (Supabase)

Опис **структури** бази магазину (проєкт `cozyhousevibe`): таблиці, правила доступу (RLS), тригери, функції.
**Тут немає даних** (товарів, замовлень, клієнтів) **і немає секретів** (Telegram-токен зберігається в Supabase Vault).

| Файл | Розділ | Що всередині |
|---|---|---|
| `schema/00_base.sql` | Основа | розширення, схема `private`, адміни + перевірка 2FA (`is_admin`), журнал змін `audit_log` |
| `schema/01_customers.sql` | 👥 Клієнти | `profiles` (акаунти — у вбудованій `auth.users`), автостворення профілю, список покупців для кабінету |
| `schema/02_catalog.sql` | 📦 Товари | `categories`, `products` (варіанти, SEO, залишки, порядок), сховище фото `product-images` |
| `schema/03_reviews.sql` | ⭐ Відгуки | `reviews`, модерація, «Verified purchase», ліміт 5 на день |
| `schema/04_orders.sql` | 🧾 Замовлення | `orders`, перевірка checkout і цін, доставка ($ з налаштувань) і податок з продажів за штатом, списання/повернення залишку, статуси, оплата, трекінг для гостей |
| `schema/05_support.sql` | 💬 Підтримка | форма «Contact us» (`messages`) і чат (`chat_threads`, `chat_messages`) |
| `schema/06_settings.sql` | ⚙️ Налаштування | `store_settings` (один рядок з усіма налаштуваннями магазину) |
| `schema/07_notifications.sql` | 🔔 Telegram | сповіщення про замовлення, повідомлення, чат, закінчення товару |
| `schema/09_suppliers.sql` | 🏭 Постачальники | довідник `suppliers` (контакти, умови) і `product_suppliers` (постачальник товару, його SKU, закупівельна ціна, посилання) — лише для адміна |
| `schema/08_returns.sql` | 🔁 Повернення | заявки покупців з фото/відео (`return_requests`), перевірка строку й товарів, Telegram-сповіщення, приватне сховище `return-media` |

**Кошик** не зберігається в базі: він живе в браузері покупця і стає замовленням (`orders.items`) при оформленні.

## Як користуватися
- **Відновити базу з нуля:** новий проєкт Supabase → SQL Editor → виконати файли по черзі `00` → `09`. Потім додати адміна (`insert into public.admins (user_id) values ('<id користувача>')`) і заново ввести Telegram-токен у кабінеті.
- **Змінюєш базу → онови тут відповідний файл** і додай запис у `CHANGELOG.md`.
- Знімок зроблено 25.11.2026 з живої бази й перевірено: усі файли виконуються без помилок.
